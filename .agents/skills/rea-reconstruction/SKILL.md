# REA reconstruction

Follow AGENTS.md and .agents/REA/README.md. Run ./bapXcms rea skills to find
the native skill(s) and current component status; load a specific adaptation
with ./bapXcms rea skill <native-id>. Use the pinned originals under
.agents/REA/reference only as research data, never as active vendor setup
instructions or executable helpers.

- Identify the current issue, exact repository head, native route/service/data
  contract and affected capability IDs before proposing changes.
- Trace the referenced pinned source path/symbol and its dependencies,
  permissions, schemas, side effects, error branches and runtime evidence.
  Expand bounded REA evidence only when required. The original source skill
  is a research guide, not evidence that its feature exists in this product.
- Record native design, stable data contract, state transitions, authorization
  and executable obligations in docs/research/rea/contracts/. Prefer existing
  domain services and transport projections over duplicate controller logic.
- Use the ability audit → design → implementation → verify sequence for tools
  and the corresponding native sections, patterns, interactivity, REST,
  performance, environment or release skill for other work.
- Validate actual representative data and negative boundaries, not only static
  maps, HTTP success, canned replies or screenshots. Mark fixture and live
  evidence separately. No new WordPress or WooCommerce runtime, broad commerce
  parity, paid dependency or production credential mutation.
- Record the selected skills and outcome in the issue/contract and append-only
  register review. Run ./bapXcms rea skills-check, ./bapXcms update and
  ./bapXcms ci, then verify exact-head CI and deployed source when applicable.

- After a verified issue loop, use the current register and open issues to select and start the next clear authorized loop. Report actual completed work, remaining gates and concrete next steps; ask for a product decision only when evidence cannot resolve the direction. Do not inflate coverage for partial migration.
