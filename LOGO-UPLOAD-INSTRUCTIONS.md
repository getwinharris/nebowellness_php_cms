# Nebo Logo Upload Instructions

## Required Logo Files

The code has been updated to use Nebo Lifestyle Clinic branding, but the actual logo image files need to be uploaded.

### Option 1: Via Admin Interface (Recommended)

1. Log in to https://nebowellness.com/admin
2. Go to **Appearance → Logo & Favicon**
3. Upload files:
   - **Logo**: The full Nebo logo (mountains + caduceus + text) - PNG with transparent background
   - **Favicon**: 64×64 px crop of just the caduceus symbol or circle

### Option 2: Via FTP/File Manager

Upload these files to the `assets/images/` directory:

1. **nebo-logo.png** - Full logo, ~200-400px wide, transparent background
2. **nebo-logo-small.png** - Small version for header, 52×52 or 100×100px
3. **nebo-logo-square.png** - Square version, 512×512px for PWA/social sharing
4. **nebo-favicon.png** - Favicon, 64×64px, just the caduceus or circle symbol

### Logo Specifications

From the provided design:
- **Colors**: Blue #4472C4 (mountains, "NEBO" text), Green #70AD47 (caduceus, "LIFESTYLE CLINIC" text)
- **Elements**: Mountains, medical caduceus symbol, "NEBO" in bold blue, "LIFESTYLE CLINIC" in green
- **Background**: Transparent or white

## After Upload

Once uploaded, verify:
1. Homepage header shows Nebo logo
2. Browser tab shows Nebo favicon
3. Mobile/PWA install uses Nebo icons
4. Social sharing (Facebook/Twitter) uses correct logo
